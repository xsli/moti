# 知识沉淀

入口：讲次顶部、批量选题工具栏、单题详情。整讲始终取该小组的完整题目，不受列表筛选和分页影响；选题模式只处理选中的题目。

每次最多40题，输入超过160,000字符时提示拆分，不静默截断。服务端读取完整题目，复用现有本地AI配置，生成核心知识、题型方法、检查顺序、自测和逐题收获。输出引用必须来自输入题目，逐题收获必须完整且不重复。图片优先使用原始配图；不支持或超过24张的图片会明确告知模型，不能据此推测条件。

结果保存在应用数据库的独立 `knowledge_reports` 表，按本地用户及讲次/所选题集区分。不修改题目的题干、答案、笔记或图片。原题内容与范围变化时显示过期提示；生成失败保留旧笔记；并发编辑或生成通过条件更新避免覆盖较新的版本。

笔记可编辑文字和公式，可导出PDF或Markdown。PDF使用A4墨绿笔记模板，包含独立方法页、批注留白、自测与分离的答案页、逐题索引。文字可选择，公式为矢量内容；内部引用可跳到索引，索引链接可打开本机原题。导出读取当前已保存版本，编辑时需先保存或取消；原题已变化的旧笔记会在PDF中标注。

PDF复用本机Tectonic编译器与资源缓存，首次准备运行 `npm run latex:setup`。正常导出仅使用缓存资源，禁止TeX执行外部命令，数学公式经过命令白名单检查。相同内容复用PDF缓存；排版失败保留笔记与Markdown导出。

重新提炼会替换当前笔记。当前题库JSON导入/导出尚不包含这张独立表，迁移或备份笔记请另用“导出 PDF”或“导出 Markdown”；数据库整体备份包含它。

数学结论由AI归纳，不等于形式化验证。待核对条件集中展示，用户可依据原题修正笔记。

验证：`npm run typecheck`、`npm test`、`npm run build:dev`。不要为检查构建执行会迁移数据库的 `npm run build`。
# 单题与整讲的不同方向

“知识沉淀”入口与“阅读”一致，进入独立的 `/knowledge` 页面。URL 保存讲次或所选题目范围，刷新和直接打开均能读回已保存笔记；返回按钮保留来源讲次、题目及其查询参数。没有弹窗遮罩或关闭按钮。未保存的编辑及生成、保存、导出期间会保护路由离开与浏览器关闭；纯阅读时可直接返回。单题、整讲、多题仍按原来的 scope_key 独立保存。

整讲方法卡会附上讲解中首先提及的关联原题全文（无法识别原题编号时选第一道关联题）；文末按原题顺序保留全部题干、选项、小问与方法收获。PDF 的方法引用带附录页码，附录可反向跳回方法页；网页内可直接展开任意引用的完整题目。题干直接取题库，不由 AI 改写，不会因补充原题而重新生成知识归纳。

新笔记保存所有原题的题干与配图快照。旧笔记仅在原题指纹完全一致时补齐当前原题，原题变化后不把新题干拼入旧归纳；缺失的旧快照会明确标出。配图保留所在小问与题干内的位置，PDF 支持题库保存的 PNG/JPEG；不支持或损坏的图会阻止导出并给出提示，不静默丢图。

单题采用“单题思路复盘”：保存原题题干快照，梳理题面线索、突破口、推理链、具体卡点，再用解释题、改变条件的自拟变式和边界判断检查迁移。通常只保留一条主解法，有必要时才比较另一条。

整讲采用“整讲方法体系”：先提供带分支的方法选择路线，再归并核心知识、题型方法卡、代表题对照和跨题型自测，最后保留逐题索引。多题勾选采用“多题方法归纳”，只概括当前选题，不声称覆盖整讲。

三者仍使用独立的 scope_key，互不覆盖，也不会自动拼接已有单题笔记。新报告持久化 kind 与 promptVersion=2；旧报告可正常读取和导出，页面提示可重新提炼，不自动调用 AI。编辑不改变笔记类型。Markdown、页面展示及 PDF 均按报告范围使用对应标签；单题 PDF 为蓝色思路复盘布局，整讲为绿色选法路线与方法卡布局。
