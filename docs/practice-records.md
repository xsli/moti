# 当前状态与练习记录

当前状态只显示“未练习、待订正、待巩固、已掌握”。旧 `new` 状态在读取时统一为“未练习”，不再提供单独的旧状态选项。这只是状态归并，不证明历史上从未做过；旧题的历史次数仍为未知。手动更改状态不新增练习记录，不增加或清空错误次数。

每次练习记录时间、独立做对/做错了/看提示才会、可选错因。记录后默认进入“待巩固”，独立做对达到掌握条件时进入“已掌握”；“待订正”仍可手动选择。“做错了”和“看提示才会”都计入错题次数及连续错误次数，并重置连续成功；历史中仍区分两种结果。已有的“看提示才会”记录按同一规则统计，无需重新记录或改写历史。详情和阅读页可记录及撤销最近一次，复习页可在提交后撤销。

详情页顶部和阅读页每题顶部提供“增加练习记录”入口：弹窗内选择结果和错因，点击“保存记录”才写入；不预选结果，取消或关闭不新增记录，重新打开清空未保存的选择。下方练习记录区域仅展示统计、历史及撤销。保存失败保留弹窗与所选内容，保存期间防止重复提交。

连续三次、相邻计入次数至少间隔 24 小时的独立做对后自动标为已掌握。同一天反复点击不会增加掌握进度；失败或需要提示重置进度。累计错误不随掌握而清零。

数据库新增可空 `practice_history_json`。旧行不回填；没有记录时显示“历史次数未记录”，随后显示“已记录错 N 次 · 更早次数未知”。新录入和新变式从已知的空记录开始。原有 `review_count` 不能用于推算错误或连续成功。

“错过的题”筛选已记录错误 ≥1，“反复出错”筛选 ≥2；可独立筛选当前状态并按错误次数降序排列。历史不明且未记录错误的题不会误入反复出错集合。排序不改写原题顺序。

记录和撤销采用服务端读取及条件更新，并用事件 ID 防止相同请求重复计数。只写练习状态相关列；不修改题干、解析或配图。JSON 导入导出和本地缓存保留记录；导入缺少新字段的旧备份不会清空数据库已有练习记录。

验证：`npm test`、`npm run typecheck`、`npm run build:dev`；`node scripts/practice-regression.mjs` 在独立临时数据库和 8098 端口验证 API 持久化、旧数据兼容、筛选、刷新、撤销和并发，不写入真实题库。
