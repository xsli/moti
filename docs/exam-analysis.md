# 试卷分析

试卷类型小组顶部的“分析卷子”打开 `/exam-analysis/$id`。分布与关联、整体阅读共用一份持久化报告。初次进入不调用 AI；点击“开始分析”“重新分析”或“重新分析本题”才调用 AI。

## 关联与统计

每道原题保存知识点、条件结构、核心解法和关联列表。关联分为原题、变形题、方法相似、补充训练，记录相关小问、共同点、差异、推荐状态和核对状态。可手动检索添加、移除、确认核对。页面不显示选题框，选题集中在 PDF 导出弹窗中。报告只存引用和人工核对的节选内容，不修改原题。

大组与讲次分布按条件/解法关联统计，不按章名匹配。讲次内部按同题族去重，小问可独立计数；覆盖只统计前三类。当前排序公式：原题×5＋变形×3＋方法×1＋覆盖原卷题数×2。跨大组/讲次可收录同题，不能把各行数量直接相加当作独立题量。

整体阅读默认使用推荐练习，并跨原卷题号去重：重复族第一次出现时保留一份。可切换全部关联、关联类别、讲次及答案显示。原题始终在每组最前面。题干直接显示，每道原题整块可折叠。题目和图片从服务端完整记录读取，滚动接近时才加载。小问节选保留共用题干和对应配图；无法可靠分割旧解析时明确显示“原题完整内容”，不把另一小问答案静默绑定过来。

点击“导出 PDF”弹出题目选择列表，默认选中全部原题和所有非补充题，不读取此前的选题记录，按原卷题号分组，支持逐题选择、全选本组、全选和全不选。“包含补充训练”开启时显示并选中补充题，仍可逐题取消；关闭时补充题不导出。弹窗选择仅影响本次导出，不写回推荐状态，取消或重新打开恢复默认。阅读筛选不影响导出范围。先筛选原题组再跨组去重，弹窗实时显示最终题量。导出保留原卷题号（例如只选第2、5题仍标2、5），包括分布总览、所选原题、关联练习，以及统一置后的答案解析。导出可取消；引用缺失、过期、公式或配图失败时停止，保留报告。当前复用浏览器图片型 PDF 导出，180 dpi。

## AI 检索边界

逐题提炼结构与检索关键词，在其他小组的全部题干、解析与标签中召回最多60个候选（输入总量超过150,000字符时减少候选，不截断单题）。再调用 AI 判断具体关联类型与理由，拒绝不存在的 ID、重复引用与无效小问。标题、讲次名称不参与召回打分。此召回不是穷尽性语义检索，检索范围和候选数量保存在报告中，不把未命中当作不存在同类题。

自动结果标记为 AI 建议，默认选原题/变形题，方法与补充可另行勾选。生成逐题保存；中途失败保留已保存题和未完成题的旧结果。停止不会提交正在进行的该题结果。重分析单题会替换该题的关联与勾选，不影响其他原题。模型只接收文本，不读取文件、联网或修改题库；无法从文字确定的图形条件必须标注不确定。

## 持久化与版本

独立数据库表 `exam_analyses`，主键为本地用户＋试卷小组，懒初始化。引用逐原题保存题干、答案、解析、配图和所属小组的内容指纹；练习记录变化不导致报告过期。一个题被多道原题引用时，重新分析其中一道不会自动更新其他关系的指纹。保存使用 revision 和条件写入避免并发覆盖。原卷增删/排序变化提示重分析；导出前后校验版本与引用变化。

整库数据库备份包含报告，当前题库 JSON 导入/导出不包含该独立表。真实报告、题库内容、扫描与导出文件不作为源码样例提交。
